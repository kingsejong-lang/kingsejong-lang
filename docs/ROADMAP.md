### 완료된 작업 (2026-10)

- ✅ **바이트코드 VM 을 평가기와 동치로 재작성** — 예제 51개가 `--vm` 에서도 같은 결과를 내고, 패턴 매칭·가져오기도 VM 이 직접 처리한다. 오류 위치에 열과 캐럿이 나온다.
- ✅ **조사 메서드 체이닝** — `목록을 걸러낸다(f)를 변환한다(g)` 와 `사용자의 이름을 출력한다` 가 왼쪽부터 적용된다.

- ✅ **버전 표기 단일화** — `--version`, REPL, LSP 가 `CMakeLists.txt` 의 버전 하나를 쓴다.
- ✅ **CI 강화** — Valgrind 잡이 테스트 전체를 돌리고 메모리 오류·누수가 있으면 실패한다.
- ✅ **쓰이지 않던 기능 제거** — JIT Tier 1·2, `ksjpm` 패키지 관리자.

## 💡 장기 비전

### 기술적 목표

- **아키텍처**: tree-walking 평가기 (기본) + 바이트코드 VM (`--vm`, 평가기와 동치. 값 의미는 Evaluator 의 정적 함수로 공유)
- **성능**: Python 대비 3-5배, V8 대비 80-90% (LLVM 사용 시)
- **메모리**: 효율적인 GC + 선택적 메모리 풀링
- **확장성**: 모듈 시스템, 패키지 관리자

### 철학

- **훈민정음의 디지털 후계자**: 배우기 쉽고 사용하기 편한 언어
- **한국어 프로그래밍**: 자연스러운 한국어 문법과 키워드
- **실용성**: 교육부터 프로덕션까지 활용 가능

### 커뮤니티

- **교육**: 초중고 프로그래밍 교육 도구
- **기업**: 한국 기업의 내부 도구 및 자동화
- **연구**: 한국어 NLP 및 언어 연구
- **오픈소스**: 활발한 기여자 커뮤니티

## 🛠️ 개발 가이드

### 빌드 및 테스트

```bash
# 빌드
mkdir build && cd build
cmake ..
make -j8

# 테스트
ctest --output-on-failure

# 메모리 검사
cmake -DCMAKE_CXX_FLAGS="-fsanitize=address -g" ..
make && ctest
```
